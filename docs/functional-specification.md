# 간판 한국어 학습 앱 기능 명세서

| 항목 | 내용 |
|---|---|
| 문서 버전 | 1.0 |
| 작성일 | 2026-10-15 |
| 문서 대상 | 인터랙티브 프로토타입을 설계하는 UX·UI 디자이너 |
| 제품 대상 | 한글을 천천히 읽을 수 있는 외국인 방문객·방문 예정자 |
| 기준 문서 | `PRD-SRS.md` |

## 1. 문서 목적

이 문서는 앱이 **무엇을 해야 하는지**와 사용자의 행동에 따라 **어떤 상태가 바뀌어야 하는지**를 정의한다. 디자이너는 이 문서를 기준으로 새로운 화면 구조와 인터랙션 프로토타입을 설계할 수 있다.

색상, 서체, 버튼 형태와 위치, 여백, 모서리, 그림자, 아이콘 스타일, 구체적인 정보 배치, 전환 애니메이션은 정의하지 않는다. 단, 제품의 핵심 경험인 **전체 화면 간판 이미지 스와이프**는 기능 요구사항으로 고정한다.

## 2. 제품 기능 요약

사용자는 실제 한국 거리의 간판 사진을 보고 뜻을 추측한 뒤 정답을 확인한다. 정답을 확인한 카드는 왼쪽 또는 오른쪽으로 스와이프해 다음 두 상태 중 하나로 판정한다.

- `Review`: 아직 어렵고 다시 볼 필요가 있음
- `Got it`: 현재는 이해했음

판정 결과는 이후 복습 순서에 반영된다. 사용자는 짧은 세션을 반복하면서 자주 마주치는 한국어 표현을 이미지 맥락과 함께 암기한다.

## 3. 명세 범위

### 3.1 프로토타입에서 완전히 동작해야 하는 기능

1. 첫 이용 안내
2. 학습 수준과 관심 분야 선택
3. 학습 세션 시작
4. 간판 관찰과 정답 확인
5. 전체 화면 이미지 좌우 스와이프
6. `Review`와 `Got it` 판정
7. 직전 판정 실행 취소
8. 세션 중단과 재개
9. 세션 완료 결과
10. 이미지 확대
11. 발음 재생 또는 재생 시뮬레이션

### 3.2 대표 경로까지 연결해야 하는 기능

1. 진행 현황 확인
2. 복습 카드 목록과 상세 확인
3. 세션 길이 변경
4. 로마자 표기 설정
5. 자동 발음 재생 설정
6. 모션 감소 설정
7. 복습 알림 설정
8. 카드 오류 신고
9. 게스트·계정 상태 안내

### 3.3 프로토타입 범위 밖

- 실제 Apple·Google 인증
- 실제 서버 동기화와 다중 기기 병합
- 실제 푸시 알림 발송
- 결제, 광고, 구독
- 실시간 카메라 촬영과 OCR
- 콘텐츠 운영 도구
- 실제 계정 삭제 처리
- 실제 분석 이벤트 전송

범위 밖 기능은 필요한 경우 결과 상태만 시뮬레이션할 수 있다.

## 4. 고정 기능과 디자이너 결정 영역

### 4.1 고정해야 하는 기능

- 간판 이미지는 학습 화면 전체를 덮는 방식으로 표시한다.
- 사용자는 정답을 확인한 뒤에만 카드를 판정할 수 있다.
- 왼쪽 스와이프는 `Review`, 오른쪽 스와이프는 `Got it`이다.
- 스와이프와 같은 결과를 만드는 대체 조작을 제공한다.
- 한 세션의 기본 카드 수는 10장이다.
- 직전 판정은 다음 카드를 판정하기 전까지 한 번 취소할 수 있다.
- 진행 중 세션을 나가더라도 완료한 카드와 현재 위치를 유지한다.
- 정답 화면에서 한국어, 의미, 단어 풀이, 발음, 맥락 설명을 확인할 수 있다.

### 4.2 디자이너가 결정할 수 있는 항목

- 기능을 실행하는 컨트롤의 형태와 위치
- 정답 정보의 구체적인 구성 방식
- 진행도와 상태를 표현하는 시각 방식
- 화면 간 이동 애니메이션
- 스와이프 판정 피드백의 시각 표현
- 홈과 진행 화면의 정보 배치
- 이미지 위 정보 가독성을 확보하는 시각 처리
- 완료와 오류 상태의 시각적 분위기

기능 실행 가능성과 상태 구분은 색상이나 제스처 하나에만 의존하면 안 된다.

## 5. 사용자 및 기본 전제

### 5.1 주요 사용자

- 한글 자모와 기본 음가를 알고 있다.
- 실제 간판에 쓰인 단어와 표현에는 익숙하지 않다.
- 한국을 방문할 예정이거나 현재 체류 중이다.
- 하루 3~5분의 짧은 학습을 선호한다.
- 앱의 기본 인터페이스 언어는 영어로 가정한다.

### 5.2 기본값

| 항목 | 기본값 |
|---|---|
| 계정 상태 | 게스트 |
| 세션 길이 | 10장 |
| 로마자 표기 | 끔 |
| 자동 발음 재생 | 끔 |
| 복습 알림 | 끔 |
| 모션 감소 | 운영체제 설정을 따름 |

## 6. 핵심 용어

| 용어 | 정의 |
|---|---|
| Sign card | 한 개의 간판 표현을 가르치는 학습 단위 |
| Question state | 정답을 숨긴 채 간판을 관찰하는 상태 |
| Answer state | 정답과 설명을 확인하고 판정할 수 있는 상태 |
| Review | 사용자가 어렵다고 판정한 상태 |
| Got it | 사용자가 이해했다고 판정한 상태 |
| Session | 연속해서 학습하는 카드 묶음 |
| Due | 복습 예정 시간이 지난 카드 |
| Mastered | 반복 성공 기준을 충족한 카드 |
| Undo | 직전 카드 판정을 취소하는 기능 |

사용자에게는 `Wrong`, `Fail`, `Dislike` 같은 표현을 사용하지 않는다.

## 7. 전체 기능 흐름

```text
앱 실행
├─ 첫 이용 → 제품 소개 → 조작 안내 → 수준 선택 → 관심 분야 선택 → 홈
└─ 재방문 → 홈

홈
├─ 새 세션 시작
├─ 중단 세션 재개
├─ 카테고리 세션 시작
├─ 진행 현황 확인
└─ 설정 확인

학습 세션
├─ 간판 관찰
├─ 정답 확인
├─ 왼쪽 Review / 오른쪽 Got it
├─ 다음 카드
├─ 직전 판정 취소
├─ 세션 중단·재개
└─ 마지막 카드 판정 → 세션 완료

진행 현황
├─ 학습 통계 확인
├─ 복습 카드 목록
└─ 카드 상세 → 1장 연습
```

이 흐름은 목적지와 상태 변화만 고정한다. 화면 이동을 어떤 모션으로 표현할지는 이 문서의 범위가 아니다.

### 8.2 전역 이동 규칙

- 사용자는 홈, 진행 현황, 설정의 세 주요 영역에 언제든 접근할 수 있다. 접근 방식과 시각 표현은 디자이너가 정한다.
- 학습 세션 중에는 실수로 세션을 잃지 않도록 종료 여부를 확인한다.
- 확대, 신고, 확인 단계가 열려 있을 때 뒤로가기는 해당 단계를 먼저 닫는다.
- 중단된 학습 세션이 있더라도 앱 실행 시 자동으로 열지 않는다.
- 온보딩을 완료한 사용자는 다시 앱을 열었을 때 홈으로 진입한다.
- 같은 기능 화면으로 돌아오면 가능한 경우 이전 탐색 위치와 카드 상태를 복원한다.
- 화면 이동 효과와 애니메이션 방식은 기능 결과에 영향을 주지 않는다.

## 9. 기능 상세 명세

### 9.1 F-APP-01 초기 상태 판별

**목적:** 앱 실행 시 사용자가 이어서 해야 할 흐름을 결정한다.

**입력 상태:**

- 온보딩 완료 여부
- 중단된 세션 여부
- 저장된 사용자 설정
- 알림 또는 특정 카드 진입 정보

**처리 규칙:**

1. 온보딩을 완료하지 않은 사용자는 제품 소개로 진입한다.
2. 온보딩을 완료한 사용자는 홈으로 진입한다.
3. 중단된 세션이 있으면 홈에서 재개 기능을 가장 먼저 제공한다.
4. 중단 세션을 사용자의 확인 없이 자동으로 열지 않는다.
5. 프로토타입에서는 저장 상태를 미리 설정하거나 로컬 상태로 시뮬레이션할 수 있다.

### 9.2 F-ONB-01 제품 소개

**목적:** 사용자가 앱의 가치와 대상 학습 내용을 이해한다.

**필수 정보:**

- 실제 거리·상점·교통 환경에서 보는 한국어를 학습한다는 설명
- 계정 없이 시작할 수 있다는 안내

**사용자 행동과 결과:**

- 시작 행동 → 학습 조작 안내로 이동
- 시스템 뒤로가기 → 앱 종료 또는 이전 앱 상태로 복귀

### 9.3 F-ONB-02 학습 조작 안내

**목적:** 정답 확인과 좌우 판정의 의미를 첫 세션 전에 학습시킨다.

**필수 동작:**

1. 예시 간판에서 정답을 확인한다.
2. 정답 확인 전 스와이프는 판정되지 않는다.
3. 정답 확인 후 왼쪽 또는 오른쪽 판정을 한 번 실행한다.
4. 제스처를 사용할 수 없으면 대체 조작으로 같은 단계를 완료할 수 있다.
5. 튜토리얼 판정은 실제 학습 기록에 포함하지 않는다.

**완료 조건:** 정답 확인과 한 번의 판정이 끝나면 다음 단계로 이동할 수 있다.

### 9.4 F-ONB-03 수준 선택

**선택값:**

- Beginner: 한글을 천천히 읽을 수 있음
- Elementary: 흔한 단어와 짧은 표현을 읽을 수 있음
- Not sure: 쉬운 카드부터 시작

**규칙:**

- 한 개만 선택할 수 있다.
- 선택하지 않고 건너뛰면 Beginner로 저장한다.
- 선택값은 초기 카드 난이도 비율에만 영향을 준다.
- 사용자의 능력을 시험하거나 합격·실패로 평가하지 않는다.

### 9.5 F-ONB-04 관심 분야 선택

**선택값:** 음식·식당, 카페·음료, 교통, 쇼핑, 생활 장소, 주의·안내.

**규칙:**

- 여러 개를 선택할 수 있다.
- 아무것도 선택하지 않아도 계속 진행할 수 있다.
- 선택이 없으면 모든 카테고리를 비슷한 비율로 사용한다.
- 완료 시 온보딩 완료 상태를 먼저 저장한 뒤 홈으로 이동한다.

### 9.6 F-HOME-01 오늘의 학습 상태 확인

**목적:** 사용자가 현재 가능한 학습과 예상 학습량을 확인한다.

**필수 데이터:**

- 세션 카드 수
- 예상 소요 시간
- 새 카드 수
- 복습 카드 수
- 중단 세션의 완료 수와 전체 수
- 현재 복습 대기 수

**상태별 기능:**

| 상태 | 제공해야 하는 기능 |
|---|---|
| 첫 이용 | 첫 세션 시작 |
| 일반 | 새 카드와 복습 카드가 섞인 세션 시작 |
| 중단 세션 있음 | 기존 위치부터 세션 재개 |
| 복습 카드 있음 | 복습 우선 세션 시작 |
| 오늘 세션 완료 | 추가 연습 또는 카테고리 학습 |
| 학습 카드 없음 | 더 학습할 카드가 없음을 안내 |
| 오프라인·저장 카드 있음 | 저장된 카드로 세션 시작 |
| 오프라인·저장 카드 없음 | 연결 후 다시 시도 |

### 9.7 F-SES-01 세션 생성

**입력:** 기본 세션, 카테고리, 복습 전용, 특정 카드 연습 중 하나.

**처리:**

1. 선택한 세션 길이에 맞춰 카드 목록을 만든다.
2. 기본 세션은 복습 카드와 새 카드를 함께 포함한다.
3. 첫 카드를 표시하기 전에 필요한 이미지와 카드 정보를 준비한다.
4. 다음 카드 최소 한 장을 미리 준비한다.
5. 준비에 실패하면 재시도와 홈 복귀를 제공한다.

**프로토타입 규칙:** 고정된 로컬 카드 목록으로 세션 생성 동작을 시뮬레이션해도 된다.

### 9.8 F-SES-02 세션 중단·재개

**중단 시 저장할 값:**

- 세션 카드 목록
- 현재 카드 위치
- 완료한 판정
- 직전 판정 취소 가능 여부
- 시작 시각과 마지막 활동 시각

**규칙:**

- 학습 중 종료 행동이나 시스템 뒤로가기를 실행하면 중단 여부를 확인한다.
- 계속 학습을 선택하면 현재 상태를 유지한다.
- 나가기를 선택하면 세션을 `paused`로 저장하고 홈으로 이동한다.
- 홈에서 재개하면 아직 판정하지 않은 카드부터 이어진다.
- 중단 세션을 버리고 새 세션을 시작하는 경우 사용자의 확인을 받아야 한다.

### 9.9 F-CARD-01 간판 관찰

**목적:** 정답 없이 실제 간판을 관찰하고 읽기와 의미를 추측한다.

**필수 데이터:**

- 간판 이미지
- 장면 대체 설명
- 학습 대상 영역 정보
- 카테고리
- 난이도
- 현재 카드 순서와 전체 카드 수

**고정 요구사항:**

- 간판 이미지는 학습 화면 전체를 덮는 방식으로 표시한다.
- 정답 한국어, 번역, 로마자 표기는 노출하지 않는다.
- 사용자는 정답 확인, 이미지 확대, 세션 종료, 문제 신고를 실행할 수 있다.
- 정답 확인 전 좌우 스와이프로 학습 상태가 바뀌지 않는다.

**정답 전 스와이프:**

1. 이미지는 제한적으로 사용자의 움직임에 반응할 수 있다.
2. 손을 놓으면 원래 상태로 복귀한다.
3. 판정 이벤트나 학습 기록을 만들지 않는다.
4. 정답을 먼저 확인해야 한다는 안내를 제공한다.

### 9.10 F-CARD-02 정답 확인

**목적:** 사용자가 자신의 추측을 확인하고 표현을 학습한다.

**필수 정보:**

1. 사진에 보이는 정확한 한국어
2. 문맥에 맞는 자연스러운 영어 의미
3. 단어 또는 형태소 풀이
4. 발음 재생 기능
5. 짧은 사용 맥락 또는 문화 설명
6. 설정이 켜진 경우 로마자 표기

**규칙:**

- 같은 카드의 Question state에서 Answer state로 바뀐다.
- 정답 확인 이벤트는 카드당 한 번만 기록한다.
- 정답을 확인한 뒤 스와이프 판정과 대체 판정 조작이 활성화된다.
- 정답 내용이 길면 사용자가 전체 정보를 확인할 수 있어야 한다.
- 정답을 확인했다는 이유만으로 카드가 완료되지는 않는다.

### 9.11 F-CARD-03 전체 화면 이미지 스와이프 판정

**목적:** 간판을 보고 암기한 결과를 직접 조작으로 빠르게 분류한다.

#### 9.11.1 기본 원칙

- 간판 사진이 화면 전체를 덮은 상태에서 스와이프한다.
- 사진과 해당 카드 정보는 하나의 학습 단위로 판정한다.
- 정답 확인 이후에만 판정이 가능하다.
- 왼쪽은 `Review`, 오른쪽은 `Got it`으로 고정한다.
- 방향은 세션 또는 설정에 따라 바뀌지 않는다.

#### 9.11.2 제스처 판별

1. 사용자가 학습 영역에서 포인터 또는 손가락을 누르면 추적을 시작한다.
2. 이동량이 12pt를 넘으면 가로 또는 세로 의도를 판별한다.
3. `가로 이동량 > 세로 이동량 × 1.2`이면 가로 판정 제스처로 잠근다.
4. 그 외에는 세로 정보 탐색으로 처리하고 판정 제스처를 실행하지 않는다.
5. 발음, 확대, 링크, 기타 독립 기능에서 시작한 입력은 카드 스와이프로 바꾸지 않는다.

#### 9.11.3 판정 임계값

- 가로 이동이 화면 너비의 25% 이상이면 해당 방향으로 판정을 확정한다.
- 25% 미만에서 입력이 끝나면 판정하지 않고 원래 상태로 복귀한다.
- 프로토타입에서는 속도만으로 판정을 확정하지 않고 이동 거리 기준만 사용한다.
- 한 번의 입력은 최대 한 번의 판정만 만든다.

#### 9.11.4 기기 경계 처리

- 포인터가 프로토타입의 기기 경계를 벗어나면 실제 터치가 끝난 것으로 처리한다.
- 마지막 기기 내부 좌표를 기준으로 임계값 충족 여부를 판단한다.
- 카드는 기기 프레임 밖의 포인터를 계속 따라가지 않는다.
- 학습 콘텐츠는 기기 화면 영역 밖에 그려지지 않아야 한다.

#### 9.11.5 판정 결과

| 방향 | 결과 | 데이터 변화 |
|---|---|---|
| 왼쪽 | Review | 복습 필요 상태로 기록하고 가까운 시점에 다시 노출 |
| 오른쪽 | Got it | 이해 상태로 기록하고 다음 복습 간격을 늘림 |

판정이 확정되면 다음 카드를 표시하고 세션 진행도를 1 증가시킨다. 다음 카드가 없으면 세션 완료 상태로 이동한다.

### 9.12 F-CARD-04 대체 판정 조작

**목적:** 제스처를 발견하지 못했거나 사용할 수 없는 사용자도 동일한 기능을 수행한다.

**규칙:**

- `Review`와 `Got it`을 각각 직접 실행할 수 있어야 한다.
- 구체적인 UI 형태는 디자이너가 결정한다.
- 정답 확인 전에는 실행할 수 없다.
- 실행 결과, 기록, 다음 카드 이동, 실행 취소 가능성은 스와이프와 완전히 같아야 한다.
- 화면 읽기 도구는 각 기능의 의미와 결과를 설명해야 한다.

### 9.13 F-CARD-05 직전 판정 취소

**목적:** 방향을 잘못 선택한 사용자가 즉시 복구한다.

**활성 조건:**

- 직전 카드가 판정된 상태
- 현재 카드는 아직 판정하지 않은 상태
- 세션이 완료되지 않은 상태

**처리:**

1. 직전 판정 기록을 취소한다.
2. 직전 카드의 복습 일정과 숙련 상태를 이전 값으로 되돌린다.
3. 직전 카드를 Answer state로 복원한다.
4. 현재 카드 위치를 직전 위치로 되돌린다.
5. 한 번 취소한 작업을 다시 취소할 수는 없다.

다음 카드를 판정하거나 취소 가능 시간이 끝나면 Undo 기능을 제거한다. 프로토타입의 기본 노출 시간은 4초로 한다.

### 9.14 F-CARD-06 이미지 확대

**기능:**

- Question state와 Answer state 모두에서 실행할 수 있다.
- 1배부터 최대 4배까지 확대할 수 있다.
- 확대 상태에서 이미지를 이동하고 원래 크기로 복귀할 수 있다.
- Question state에서 진입하면 정답을 노출하지 않는다.
- Answer state에서 진입하면 현재 정답을 함께 확인할 수 있다.
- 닫으면 기존 카드 상태와 정보 탐색 위치를 복원한다.

확대 화면의 구체적인 배치와 제스처 피드백은 디자이너가 결정한다.

### 9.15 F-CARD-07 발음 재생

**규칙:**

- Answer state에서 한국어 표현의 발음을 재생한다.
- 재생 중 다시 실행하면 처음부터 다시 재생한다.
- 다른 카드로 이동하면 기존 재생을 중지한다.
- 자동 재생 설정이 켜져 있으면 Answer state 진입 후 한 번 재생한다.
- 오디오가 없거나 실패하면 학습을 막지 않고 사용할 수 없음을 안내한다.

프로토타입에서 실제 음원이 없으면 재생 중·완료·실패 상태를 시뮬레이션할 수 있다.

### 9.16 F-CARD-08 카드 신고

**신고 유형:**

- 한국어 표기 오류
- 영어 의미 오류
- 오디오 오류
- 부적절하거나 개인정보가 포함된 이미지
- 기타

**규칙:**

- 신고 유형은 하나만 선택한다.
- 추가 설명은 선택 사항이며 최대 500자다.
- 유형을 선택해야 제출할 수 있다.
- 연속 제출을 방지한다.
- 프로토타입은 성공 결과와 오프라인 저장 결과를 시뮬레이션한다.

### 9.17 F-DONE-01 세션 완료 결과

**완료 조건:** 계획된 모든 카드를 판정했다.

**필수 결과:**

- 완료한 카드 수
- `Review` 수
- `Got it` 수
- 다음 복습 예정 수 또는 예정 없음

**가능한 후속 행동:**

- 홈으로 돌아가기
- 이번 세션의 Review 카드 보기
- 복습 알림 설정

Review 카드가 없으면 Review 카드 보기 기능은 제공하지 않는다.

### 9.18 F-PROG-01 진행 현황 확인

**필수 정보:**

- 한 번 이상 판정한 카드 수
- Mastered 카드 수
- 현재 복습 가능한 카드 수
- 최근 7일 학습 기록
- 카테고리별 학습 상태
- Review 카드 일부

**상태:**

- 기록 있음: 저장된 집계를 표시한다.
- 기록 없음: 첫 세션 시작 기능을 제공한다.
- 오프라인: 기기에 마지막으로 저장된 값을 표시한다.

### 9.19 F-PROG-02 복습 카드 탐색

**기능:**

- 지금 복습할 카드와 전체 Review 카드를 구분해서 볼 수 있다.
- 카테고리, 난이도, 최근 판정일로 결과를 좁힐 수 있다.
- 복습 기한이 오래된 카드부터 우선 표시한다.
- 카드 상세에서 정답, 발음, 맥락, 학습 상태를 확인한다.
- 상세 정보만 보는 것은 학습 판정으로 기록하지 않는다.
- 복습 시점이 된 카드는 해당 카드만 연습하는 세션을 시작할 수 있다.

### 9.20 F-SET-01 학습 설정

| 설정 | 선택값 | 반영 시점 |
|---|---|---|
| 세션 길이 | 5장, 10장, 20장 | 다음 새 세션부터 |
| 로마자 표기 | 켬, 끔 | 현재 카드부터 |
| 자동 발음 재생 | 켬, 끔 | 다음 Answer state부터 |
| 복습 알림 | 켬, 끔, 현지 시각 | 저장 직후 |
| 모션 감소 | 켬, 끔 또는 시스템 설정 | 저장 직후 |

설정 변경은 즉시 저장한다. 저장에 실패하면 이전 값으로 복구하고 실패를 안내한다.

### 9.21 F-REM-01 복습 알림 설정

**규칙:**

- 사용자가 명시적으로 켠 경우에만 활성화한다.
- 기본 시각은 사용자 현지 시각 오후 7시다.
- 복습할 카드가 없으면 알림을 보내지 않는다.
- 운영체제 권한을 요청하기 전에 알림의 목적을 설명한다.
- 권한이 거부된 경우 시스템 설정으로 이동할 수 있음을 안내한다.
- 프로토타입에서는 권한 허용·거부 결과를 선택 가능한 상태로 시뮬레이션한다.

### 9.22 F-ACC-01 계정 상태 안내

**게스트 상태:**

- 학습 기록이 현재 기기에 저장됨을 안내한다.
- 계정 연결 시 동기화와 복원이 가능함을 안내한다.
- 로컬 학습 기록 초기화 기능을 제공한다.

**연결 상태:**

- 연결된 인증 제공자
- 마스킹한 계정 식별 정보
- 마지막 동기화 시각
- 정상, 진행 중, 실패 중 하나의 동기화 상태
- 로그아웃과 계정 삭제 요청

프로토타입에서는 실제 개인정보를 입력받지 않고 상태 전환만 시뮬레이션한다.

## 10. 상태 모델

### 10.1 카드 상태

```text
Question
├─ 정답 확인 → Answer
├─ 정답 전 스와이프 → Question 유지
├─ 이미지 확대 → Viewer → Question 복귀
└─ 세션 종료 → Paused 또는 Question 유지

Answer
├─ 왼쪽 판정 → Rated: Review
├─ 오른쪽 판정 → Rated: Got it
├─ 대체 조작 → 해당 Rated 상태
├─ 이미지 확대 → Viewer → Answer 복귀
└─ 세션 종료 → Paused 또는 Answer 유지

Rated
├─ Undo → 이전 카드 Answer
├─ 다음 카드 존재 → 다음 Question
└─ 다음 카드 없음 → Session completed
```

### 10.2 세션 상태

| 상태 | 의미 | 허용되는 다음 상태 |
|---|---|---|
| Idle | 활성 세션 없음 | Preparing |
| Preparing | 카드 목록과 자산 준비 중 | Active, Error, Idle |
| Active | 학습 진행 중 | Paused, Completed, Error |
| Paused | 중단 위치가 저장됨 | Active, Cancelled |
| Completed | 모든 카드 판정 완료 | Idle |
| Cancelled | 사용자가 기존 세션을 폐기함 | Preparing, Idle |
| Error | 세션을 계속할 수 없는 오류 | Preparing, Idle |

### 10.3 카드 학습 상태

| 판정 | 첫 노출 후 기본 처리 |
|---|---|
| Review | 현재 세션의 뒤쪽에서 한 번 더 노출할 수 있으며 다음 날 복습 대상으로 지정 |
| Got it | 3일 뒤 복습 대상으로 지정 |

복습에서 연속으로 Got it을 선택하면 복습 간격을 늘린다. Review를 선택하면 숙련 단계를 낮추고 가까운 시점에 다시 노출한다. 프로토타입에서는 정확한 일정 계산 대신 결과 문구와 분류만 시뮬레이션해도 된다.

## 11. 카드 데이터 계약

각 학습 카드에는 다음 데이터가 필요하다.

| 필드 | 필수 | 용도 |
|---|---|---|
| `id` | 예 | 카드 식별 |
| `image` | 예 | 전체 화면 간판 사진 |
| `image_alt_question` | 예 | 정답을 포함하지 않은 장면 설명 |
| `focus_region` | 예 | 사진 속 학습 대상 영역 |
| `korean_text` | 예 | 사진에 보이는 한국어 |
| `english_meaning` | 예 | 문맥에 맞는 영어 의미 |
| `word_breakdown` | 예 | 1~4개 단어 또는 형태소 풀이 |
| `pronunciation_audio` | 예 | 발음 음원 또는 재생 상태 |
| `romanization` | 선택 | 설정이 켜진 경우 표시 |
| `context_note` | 선택 | 사용 장소 또는 문화 설명 |
| `category` | 예 | 콘텐츠 분류 |
| `difficulty` | 예 | 초기 카드 구성 기준 |

Question state의 대체 설명에는 정답 한국어를 포함하지 않는다. Answer state에서는 정답을 포함한 설명을 사용할 수 있다.

## 12. 공통 상태와 오류 처리

| 상황 | 기능 동작 |
|---|---|
| 네트워크 없음·저장 카드 있음 | 학습과 판정을 계속하고 나중에 동기화 |
| 네트워크 없음·저장 카드 없음 | 세션 시작을 중단하고 재시도 제공 |
| 이미지 로딩 실패 | 재시도 또는 카드 건너뛰기; 학습 실패로 기록하지 않음 |
| 오디오 실패 | 카드 학습은 계속하고 오디오만 사용할 수 없음을 안내 |
| 판정 저장 실패 | 기기에 먼저 보존하고 재전송 예정 상태로 처리 |
| 세션 준비 실패 | 재시도 또는 홈 복귀 |
| 카드 비활성화 | 해당 카드를 건너뛰고 결과 수에서 제외 |
| 중복 입력 | 첫 입력 한 번만 처리 |
| 인증 만료 | 게스트처럼 학습을 계속하고 계정 재연결을 안내 |

오류가 발생해도 이미 완료한 판정과 현재 세션 위치를 잃으면 안 된다.

## 13. 접근성 기능 요구사항

1. 스와이프가 필요한 모든 기능에는 직접 실행 가능한 대체 조작이 있어야 한다.
2. Question state의 이미지 설명은 정답을 말하지 않아야 한다.
3. Answer state에서는 한국어 정답과 의미를 읽을 수 있어야 한다.
4. 현재 카드 순서와 전체 카드 수를 하나의 진행 정보로 제공한다.
5. `Review`와 `Got it`의 의미를 색상 없이 구분할 수 있어야 한다.
6. 외부 키보드 또는 스위치 제어로 모든 핵심 기능에 도달할 수 있어야 한다.
7. 정답 확인 후에만 왼쪽·오른쪽 방향 입력을 판정으로 처리한다.
8. 모션 감소가 켜져 있어도 모든 상태 변화와 기능 결과는 동일해야 한다.
9. 발음 재생, 확대, 신고 기능에서 시작한 입력은 스와이프 판정으로 오인하지 않아야 한다.
10. 결과 안내가 나타나도 사용자의 포커스를 강제로 이동하지 않는다.

## 14. 프로토타입 연결 시나리오

### P-01 첫 사용자 핵심 경로

1. 제품 소개를 시작한다.
2. 조작 안내에서 정답을 확인한다.
3. `Review` 또는 `Got it`을 한 번 실행한다.
4. 수준과 관심 분야를 선택한다.
5. 홈에서 첫 세션을 시작한다.
6. 카드의 정답을 확인한다.
7. 왼쪽과 오른쪽 판정을 각각 경험한다.
8. 마지막 카드까지 완료한다.
9. 완료 결과를 확인하고 홈으로 돌아간다.

### P-02 정답 전 스와이프 방지

1. Question state에서 좌우로 스와이프한다.
2. 카드는 판정되지 않는다.
3. 정답 확인이 필요하다는 안내를 확인한다.
4. 정답을 확인한 뒤 같은 동작으로 정상 판정한다.

### P-03 잘못된 판정 복구

1. 정답 확인 후 의도와 다른 방향으로 판정한다.
2. 다음 카드에서 Undo를 실행한다.
3. 이전 카드가 Answer state로 복원된다.
4. 반대 방향으로 다시 판정한다.

### P-04 세션 중단과 재개

1. 세션 중간에 나가기를 시도한다.
2. 계속 학습 또는 중단을 선택한다.
3. 중단을 선택하고 홈으로 이동한다.
4. 홈에서 세션을 재개한다.
5. 마지막으로 완료한 카드 다음부터 이어진다.

### P-05 이미지와 발음 확인

1. Question state에서 이미지를 확대한다.
2. 정답이 노출되지 않는지 확인한다.
3. 원래 카드로 돌아와 정답을 확인한다.
4. 다시 확대해 정답 정보를 확인한다.
5. 발음을 재생한다.

### P-06 복습 경로

1. 세션에서 한 카드를 Review로 판정한다.
2. 세션을 완료한다.
3. 완료 결과에서 Review 카드를 확인한다.
4. 카드 상세를 확인한다.
5. 해당 카드의 1장 연습을 시작한다.

### P-07 기기 경계 스와이프

1. Answer state에서 카드를 가로로 끈다.
2. 포인터를 프로토타입 기기 경계 밖으로 이동한다.
3. 카드가 외부 포인터를 계속 따라가지 않는지 확인한다.
4. 마지막 내부 좌표가 임계값 이상이면 판정되고, 미만이면 복귀하는지 확인한다.

## 15. 기능 수용 기준

| ID | 수용 기준 |
|---|---|
| AC-01 | 계정 생성 없이 첫 학습 세션을 시작할 수 있다. |
| AC-02 | 정답 확인 전 스와이프는 어떤 학습 기록도 만들지 않는다. |
| AC-03 | 정답 확인 후 왼쪽 스와이프는 Review를 정확히 한 번 기록한다. |
| AC-04 | 정답 확인 후 오른쪽 스와이프는 Got it을 정확히 한 번 기록한다. |
| AC-05 | 대체 판정 조작은 스와이프와 동일한 결과를 만든다. |
| AC-06 | 임계값 미만의 스와이프는 판정하지 않는다. |
| AC-07 | 기기 밖으로 나간 포인터를 카드가 계속 추적하지 않는다. |
| AC-08 | Undo는 직전 카드와 학습 상태를 정확히 복원한다. |
| AC-09 | 다음 카드를 판정한 뒤에는 그 이전 판정을 취소할 수 없다. |
| AC-10 | 세션 중단 후 완료 카드 수와 현재 위치가 유지된다. |
| AC-11 | 마지막 카드 판정 후 완료 수와 방향별 판정 수가 일치한다. |
| AC-12 | Question state의 이미지 확대에서 정답이 노출되지 않는다. |
| AC-13 | 오디오 실패가 카드 판정을 막지 않는다. |
| AC-14 | 모든 스와이프 기능을 제스처 없이도 완료할 수 있다. |
| AC-15 | 모션 감소 상태에서도 기능 결과와 기록은 동일하다. |

## 16. 디자이너 전달 체크리스트

프로토타입 전달 전 다음 항목을 확인한다.

- [ ] 각 화면 또는 상태에 진입 조건이 연결되어 있다.
- [ ] 각 사용자 행동의 성공 결과가 연결되어 있다.
- [ ] Question state와 Answer state가 기능적으로 구분된다.
- [ ] 정답 전 스와이프 방지 상태가 구현되어 있다.
- [ ] 왼쪽 Review와 오른쪽 Got it이 반대로 연결되지 않았다.
- [ ] 스와이프와 대체 판정 조작의 결과가 같다.
- [ ] Undo가 이전 카드 Answer state로 돌아간다.
- [ ] 세션 중단과 재개 흐름이 연결되어 있다.
- [ ] 마지막 카드 뒤에 완료 결과가 연결되어 있다.
- [ ] 이미지 확대 전후에 정답 공개 상태가 유지된다.
- [ ] 오류·빈 상태 중 최소 한 가지 대표 사례가 포함되어 있다.
- [ ] 기기 경계 밖 포인터 추적 문제가 발생하지 않는다.
- [ ] 디자인 파일에 기능 ID 또는 상태명이 표시되어 있다.
- [ ] 색상·아이콘을 제거해도 핵심 기능을 구분할 수 있다.

## 17. 최종 산출물 권장 구조

디자이너의 파일에는 다음 산출물을 포함하는 것을 권장한다.

1. 전체 기능 흐름 맵
2. 화면 및 상태 목록
3. 핵심 경로 프로토타입
4. 전체 화면 스와이프 동작 설명
5. Question·Answer·Rated 상태 비교
6. 오류·빈 상태 모음
7. 접근성 대체 조작 설명
8. 기능 ID와 화면 연결표

시각 디자인은 자유롭게 변경할 수 있지만, 이 문서에서 `Must`로 정의한 기능 결과와 상태 규칙은 유지해야 한다.
